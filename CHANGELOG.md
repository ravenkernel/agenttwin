# Changelog

Every release is tagged in git and published on PyPI.  The tape format is
`schema 0.1` for all of them, so a tape recorded by an older release still
replays on a newer one: the package version in the fingerprint is compared
major.minor, so a patch release never invalidates a tape.

## Unreleased

Distribution work: the code and the tape format are unchanged, so there is
nothing to migrate.  The first entry is the one to read if you already looked
at the repository — the project had no published demo at all.

### Added

- `docs/`: the GitHub Pages demo.  Two pages of the ordinary single-file
  viewer (the same tape, one replay with exit 1 and one with exit 0) plus a
  landing page, generated by `tools/gen_demo_pages.py` from
  `examples/hero.py`.  `tests/test_demo_pages.py` regenerates them into a
  scratch directory and fails if the committed copies have drifted.
- `assets/hero-short.gif` (six seconds, three frames) as the image both
  READMEs open with, `assets/before-after.png` (1600×900, the static card
  for social posts) and `assets/social-preview.png` (1280×640), all built by
  `tools/make_release_assets.py`.
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CITATION.cff`,
  issue forms and a pull-request template.

### Changed

- `assets/hero.gif` is now `assets/hero-full.gif`: the four-frame walkthrough
  moved below the six-second loop instead of being the first thing a visitor
  loads.
- Both README editions carry three badges (PyPI, CI, coverage floor) and link
  the online demo.

## 0.1.2 — 2026-11-05

The first release with outside contributions, and the release that finally
makes the PyPI page match the repository.  The tape format is still `schema
0.1`: every tape recorded with 0.1.0 or 0.1.1 replays unchanged.

### Added

- `agenttwin diff A B --json [PATH]` prints or writes the comparison as JSON
  (`first_divergence_seq`, per-change counts, the changed rows) with the same
  0/1/2 exit codes.  Thanks @Doomguy-BFG9000 (#6, closes #1).
- `agenttwin gallery run <id> --html PATH` writes the fixture's report as the
  single-file viewer, keeping the Markdown output and the exit code identical.
  Thanks @Doomguy-BFG9000 (#9, closes #4).
- A `terminates_within` before/after pair in the gallery (`late_stop` /
  `early_stop`), which brings it to twelve fixture tapes in six pairs — one per
  assertion family.  Thanks @Doomguy-BFG9000 (#7, closes #2).
- Markdown reports carry a `fingerprint:` line naming the model, Python and
  package version that recorded the tape, in the same order the HTML viewer
  uses.  Thanks @Doomguy-BFG9000 (#8, closes #3).

### Fixed

- The published README pointed at `assets/hero.gif`, which this repository had
  renamed to `hero-full.gif` — so the image on the PyPI page was broken.  The
  old path is kept as a copy of the six-second loop, and the description now
  links assets that exist.

### Changed

- The PyPI description carries the badges, the six-second loop and the link to
  the online demo at <https://ravenkernel.github.io/agenttwin/>.
- `tools/gen_fixtures.py` retains each committed fixture's original
  `env_fingerprint` when regenerating, so the byte-for-byte check no longer
  depends on the machine that runs it.

## 0.1.1 — 2026-11-05

Documentation, one viewer fix and one change of meaning; the tape format is
untouched.

### Added

- `examples/hero.py` and the four-frame walkthrough (now `assets/hero-full.gif`): one committed tape replayed twice —
  faithful first (exit 1), then with a single policy key changed (exit 0).  Both
  README editions embed the animation and quote the same transcript, and
  `tests/test_hero.py` keeps that transcript equal to a real run.
- A `Changelog` link in the package metadata.

### Fixed

- The offline viewer's state-diff panel drew eighteen rows as ten-pixel slivers:
  the list is a flex column with `overflow: auto`, so every row was shrinking to
  fit instead of scrolling.  Rows keep their height now.
- `README` installation instructions now lead with `pip install agenttwin`;
  the `-e .` path is mentioned only for working on a checkout.

### Changed

- A replay that carries a patch or an explicit `policy=` now reports
  `mode: counterfactual`, and its divergence no longer forces exit code 2 — the
  assertions decide.  A faithful replay (neither supplied) still treats any
  divergence as exit 2, which is the check that catches a controller that stopped
  reproducing the recorded run.
- `fingerprint._DEFAULT_VERSION` no longer repeats the package version; the
  single source of truth is `agenttwin.__version__`.

## 0.1.0 — 2026-11-05

First public release: record / replay / counterfactual, the four drift classes,
nine assertion factories plus combinators and YAML loading, seq-aligned
`TraceDiff`, the single-file HTML viewer and report, the five `agenttwin`
commands, the openai-compatible adapter, and ten bundled fixtures in five
before/after pairs.
